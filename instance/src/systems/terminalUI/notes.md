# View Size Calculation Steps

- get available space
- get all absolute widths and heights for children with px values (include min px values if the normal val uses non px values)
- get remaining space for x & y
- calculate all total % dimensions for children
- calculate the value of a width & height percent using the remaining space
- get all absolute widths and heights for children with % values
